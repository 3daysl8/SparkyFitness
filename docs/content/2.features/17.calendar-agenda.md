## Calendar / Daily Agenda

### Home Dashboard Agenda Card
- **Day View**: Today's events in chronological order, with start/end time, title, location (or a clickable link for a virtual meeting), and a color dot identifying which calendar it came from.
- **Week View**: A stacked 7-day agenda for the current week, grouped by day.
- **Empty State**: A friendly message when nothing is scheduled for the selected day.
- **Launch Workout**: An event whose title looks like a workout (e.g. "Gym", "Leg Day") gets a one-tap button that jumps straight into starting a workout session.

### Connecting a Calendar
- Subscribe to any Google, Apple, or Outlook calendar via its private iCal (`.ics`) feed URL, added under **Settings → Developer & Integrations → Calendar Feeds**.
- Add as many calendars as you like (e.g. Work + Personal); each gets its own color and can be individually enabled or disabled without deleting it.
- The server fetches and caches each feed for 15 minutes, so the dashboard never waits on a slow external calendar provider.
- Recurring events (weekly meetings, standing habits) are expanded automatically, including edited or cancelled individual occurrences.
- Feed URLs are fetched server-side with the same private-network protections used elsewhere in the app — a feed can only point at a real public calendar provider, never at internal infrastructure.
